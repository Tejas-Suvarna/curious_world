# The Curious World

A personal, lifelong learning project about the people, ideas and forces that shape our world. This first version is a responsive static homepage featuring the planned 19 subjects. It is intentionally built with plain HTML, CSS and JavaScript so it can be opened locally and hosted on GitHub Pages without a build step.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server (for example, `python -m http.server 8000`).

## Publish with GitHub Pages

Create a GitHub repository, push this folder to its default branch, then choose **Settings → Pages → Deploy from a branch**, select the default branch and `/ (root)`, and save. GitHub Pages will serve `index.html` at the repository's Pages URL.

## Images and illustrations

Lesson images use direct HTTPS URLs with credits and links to their original sources. Lessons also use maps, timelines, diagrams, and embedded videos where they help explain the topic. See [AGENTS.md](AGENTS.md) for the project guidelines on themes, media, and quizzes.

## History & Civilisations

The [History & Civilisations curriculum](history.html) lists 60 planned modules in ten parts. [Module 1](history/universe-and-formation-of-earth.html) is available from the curriculum and includes an interactive timeline and quiz. For the YouTube players, open the site through the local HTTP server or GitHub Pages so the browser can send a referrer. Each video also has a direct watch link.
